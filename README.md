🤖 Cybersecurity FAQ Chatbot (CodeAlpha_Task-2.2)

A Python-based FAQ Chatbot that answers cybersecurity-related questions using Natural Language Processing (NLP), TF-IDF Vectorization, and Cosine Similarity.

🚀 Features

- Interactive chatbot interface.
- Cybersecurity-related FAQs.
- NLP-based text processing.
- TF-IDF Vectorization.
- Cosine Similarity for question matching.
- Automatic answer selection.
- Input validation.
- Error handling.
- Exit option to close the chatbot.

🛠️ Technologies Used

- Python
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity
- Natural Language Processing (NLP)

⚙️ How It Works

1. Collects predefined cybersecurity FAQs.
2. Converts FAQ questions into TF-IDF vectors.
3. Processes the user's question.
4. Calculates Cosine Similarity.
5. Finds the most similar FAQ question.
6. Displays the corresponding answer if the similarity score meets the threshold.

🎯 Project Objective

The main objective is to develop a simple NLP-based chatbot that helps users understand basic cybersecurity concepts through an interactive question-and-answer system.
